# Subscription Dashboard Task

## Project Structure

```bash
subscription-dashboard-task/
│
├── client/    # Frontend Application
│
├── server/    # Backend API
│
└── README.md
```

## Tech Stack Used

### Frontend

* React.js
* React Router
* Axios
* Tailwind CSS

### Backend

* Node.js
* Express.js
* PostgreSQL
* JWT Authentication

---

## Setup & Run Instructions

### Clone Repository

```bash
git clone https://github.com/your-username/subscription-dashboard-task.git
cd subscription-dashboard-task
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

### Environment Variables

Create a `.env` file inside the server folder:

```env
PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```
